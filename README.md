# Sales Business Analysis

## Project Overview

This project analyzes sales and business performance data using Python.
The goal is to identify important patterns in revenue, profit, product performance,
regional performance, customer segments, and monthly sales trends.

The project demonstrates the complete data analysis workflow, including data
exploration, data cleaning, business analysis, and data visualization.

---

## Objectives

- Analyze overall sales performance
- Identify revenue trends over time
- Analyze revenue and profit by product category
- Compare regional sales performance
- Analyze customer segment performance
- Identify products with higher sales and profit
- Analyze quantity sold by product
- Calculate profit margins
- Generate meaningful business insights

## Dataset

The dataset contains sales transaction records with information such as:

- Order ID
- Order Date
- Region
- Customer Segment
- Category
- Product
- Quantity
- Unit Price
- Discount
- Revenue
- Cost
- Profit

The dataset was used to perform data cleaning, analysis, and visualization.

---

## Data Cleaning

The following data cleaning steps were performed using Pandas:

- Checked the dataset structure
- Checked for missing values
- Identified duplicate records
- Removed duplicate rows
- Replaced missing Region values with "Unknown"
- Replaced missing Customer Segment values with "Unknown"
- Converted Order Date into datetime format
- Created a Profit Margin column
- Created a Month column for monthly analysis
